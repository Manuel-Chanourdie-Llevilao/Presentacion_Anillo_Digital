## 3. Navegar por las Diapositivas

### Usando el Ratón (Mouse) 🖱️

**Botón "Siguiente →"** (esquina inferior derecha)
- Haz clic para avanzar a la siguiente diapositiva
- Se desactiva automáticamente en la Diapositiva 5

**Botón "← Anterior"** (esquina inferior izquierda)
- Haz clic para retroceder a la diapositiva anterior
- Se desactiva automáticamente en la Diapositiva 1

**Indicador de Diapositiva**
- Muestra tu posición actual: "Diapositiva X de 5"

### Usando el Teclado ⌨️

| Tecla | Acción |
|-------|--------|
| **→** (Flecha Derecha) | Siguiente diapositiva |
| **←** (Flecha Izquierda) | Diapositiva anterior |
| **Spacebar** (Barra Espaciadora) | Siguiente diapositiva |

**Ejemplo:**
1. Abre la presentación (estás en Diapositiva 1)
2. Presiona → (pasas a Diapositiva 2)
3. Presiona ← (vuelves a Diapositiva 1)
4. Presiona Spacebar (pasas a Diapositiva 2 nuevamente)

### Atajo Rápido: Permaenlace a Diapositiva Específica

Aunque la presentación no tiene URLs de diapositivas, puedes hacer:
1. Abre la presentación
2. Navega manualmente a la diapositiva que quieras
3. Muestra esa vista a otros

  - 🛡️ Escudo Policía de la Ciudad

  - 75 Cámaras
  - 886 Lectores ANPR/LPR

  - 254 Personal
- 🎯 Funciones operativas (lado derecho)
  - 5 funciones principales con emojis
  - Certificación ISO 9001:2015

**Interactividad:**
- Hover sobre cualquier recuadro: cambia el color y se agranda ligeramente

### 4.3: Diapositiva 3 - Gráficos Interactivos

**Características:**
- 📈 Gráfico de Barras (izquierda):
  - Procedimientos: Interceptaciones, Aprehendidos, Actuaciones GAP
  - Comparativa 2025 vs 2026
  - Colores corporativos

- 📊 Gráfico de Líneas (derecha):
  - Alarmas Atendidas por región
  - Tendencia 2025 vs 2026

**Interactividad:**
1. Pasa el ratón sobre las barras/líneas
2. Aparecerá una etiqueta con el valor exacto
3. Haz clic en la leyenda para ocultar/mostrar series

**Ejemplo de Lectura:**
- Procedimientos GAP 2026: 3092 (vs 1696 en 2025) = ↑82.4% ⭐

### 4.4: Diapositiva 4 - Tablas de Análisis Detallado

**Características:**
- 📋 Tabla 1: Procedimientos Realizados
  - 5 indicadores clave
  - Cambios porcentuales (en %)
  - ✓ Todos con resultados positivos

- 📋 Tabla 2: Alarmas
  - Comparativa 2025 vs 2026
  - **Destacado:** Alarmas Atendidas ↑163.8% 🎯

**Cómo Leer:**
- Busca el ✓ en verde (resultados positivos)
- Los valores en la columna "%" indican el cambio respecto a 2025
- Valores positivos (↑) = mejora
- Valores negativos (↓) = reducción

### 4.5: Diapositiva 5 - Conclusiones y Logros

**Características:**
- 🎯 Hitos Operativos Destacados (4 puntos)
- 📊 Impacto Operacional (4 puntos)
- 📝 Caja de Conclusión (resumen ejecutivo)

**Lectura Recomendada:**
1. Lee los Hitos primero
2. Luego el Impacto
3. Finaliza con la Conclusión

## 5. Personalización Básica

### 5.1: Cambiar Colores

**Pasos:**
1. Abre `presentacion_anillo_digital.html` con un editor de texto
   - Notepad
   - Visual Studio Code (recomendado)
   - Sublime Text

2. Busca (Ctrl+F): `#2373aa`

3. Reemplaza con tu color favorito (ej: `#FF5733` para rojo)

4. Guarda (Ctrl+S)

5. Abre de nuevo en tu navegador para ver los cambios

### 5.2: Cambiar Texto

**Ejemplo: Cambiar el Título**

1. Abre `presentacion_anillo_digital.html` en editor de texto
2. Busca: `<h1>DIVISIÓN ANILLO DIGITAL</h1>`
3. Reemplaza con: `<h1>TU NUEVO TÍTULO</h1>`
4. Guarda y abre de nuevo

### 5.3: Cambiar Imágenes

**Para reemplazar un escudo:**

1. Abre `presentacion_anillo_digital.html` en editor de texto
2. Busca: `Escudo Dorado.jpeg`
3. Reemplaza la ruta con la ruta de tu imagen:
   ```
   src="C:/ruta/nueva/imagen.png"
   ```
4. Guarda y abre de nuevo

**Consejo:** Usa imágenes PNG o JPG de alta calidad

### 5.4: Cambiar Datos de Gráficos

**Para actualizar números:**

1. Busca en el código: `data: [979, 290, 1696]` (datos 2025)
2. Reemplaza con tus nuevos números
3. Repite para los datos 2026: `data: [866, 314, 3092]`
4. Guarda y abre de nuevo

## 6. Publicar en Línea

### Opción A: GitHub Pages (RECOMENDADO) ⭐

#### Paso A1: Crear Cuenta en GitHub
1. Ve a https://github.com
2. Clic en "Sign up"
3. Completa los datos
4. Verifica tu email

#### Paso A2: Crear Repositorio
1. En https://github.com, clic en el ➕ (arriba a la derecha)
2. Selecciona "New repository"
3. Nombre: `presentacion-anillo-digital`
4. Descripción: `Presentación División Anillo Digital 2026`
5. Selecciona **Public** (para que sea visible)
6. Clic en **"Create repository"**

#### Paso A3: Subir Archivos
1. Después de crear el repositorio, haz clic en **"Upload files"**
2. Arrastra `presentacion_anillo_digital.html`
3. Arrastra también `README.md`
4. Clic en **"Commit changes"**

#### Paso A4: Activar GitHub Pages
1. En tu repositorio, ve a **Settings** (⚙️)
2. Busca **"Pages"** en el menú izquierdo
3. En "Source", selecciona **"main"** branch
4. Clic en **"Save"**
5. Espera 1-2 minutos
6. ¡Tu presentación está en línea! 🎉

**URL resultante:**
```
https://tu-usuario.github.io/presentacion-anillo-digital/presentacion_anillo_digital.html
```

### Opción B: Netlify

1. Ve a https://netlify.com
2. Clic en "Sign up" (usa tu cuenta GitHub)

4. Conecta tu repositorio de GitHub

### Opción C: Vercel

1. Ve a https://vercel.com

## 7. Solución de Problemas

### Problema: Las imágenes (escudos) no cargan

**Causa:** Las rutas a los archivos pueden estar rotas

**Solución:**
1. Verifica que los archivos PNG/JPG existan en las carpetas indicadas
2. Abre con editor de texto y busca: `file:///C:/Users/chanu/OneDrive/`
3. Si tienes otra ruta, actualiza con la correcta
4. Guarda y abre de nuevo

### Problema: La presentación se ve muy pequeña

**Solución:**
- **Windows:** Presiona `Ctrl + +` repetidas veces
- **Mac:** Presiona `Cmd + +` repetidas veces
- **Restaurar:** `Ctrl + 0` (o `Cmd + 0`)

### Problema: Los gráficos no aparecen

**Causa:** Sin conexión a Internet (Chart.js se carga desde CDN)

**Solución:**
1. Conecta a Internet
2. Actualiza la página (F5)
3. Si sigue sin funcionar, revisa tu firewall

### Problema: Las transiciones son muy lentas

**Solución:**
1. Cierra otras pestañas del navegador
2. Reinicia el navegador
3. Prueba con Chrome (mejor rendimiento)

### Problema: El archivo no se abre al hacer doble clic

**Solución:**
1. Haz clic derecho en el archivo
2. "Abrir con"
3. Selecciona tu navegador (Chrome, Firefox, Edge)

### Problema: Quiero cambiar las imágenes pero no sé cómo

**Solución paso a paso:**
1. Copia tus nuevas imágenes a una carpeta
2. Abre `presentacion_anillo_digital.html` con Notepad
3. Busca (Ctrl+F): `src="file:///`
4. Actualiza la ruta a tu imagen
5. Guarda (Ctrl+S)
6. Abre en navegador
